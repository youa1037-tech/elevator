# ELEVATOR

엘리베이터 안내원 아케치와 함께 10층에서 1층까지 내려가는 관찰형 공포 게임이에요.
층마다 문이 열리면 이상한 점이 없는지 살피고, 이상이 없으면 닫힘을, 이상이 보이면 비상벨을 누르세요.

**플레이:** https://youa1037-tech.github.io/elevator/
(브라우저에서 바로 플레이, 설치 필요 없음. 세로 화면·소리 켜기 권장)

- 페르소나5 2차 창작 비공식 팬게임입니다. 아틀러스·세가와 관계없으며, 무료·비상업으로 공개합니다.
- 공포 연출, 피를 연상시키는 붉은 표현, 갑작스러운 소리가 있어요.
- 진행 상황은 플레이한 브라우저에만 저장돼요.
